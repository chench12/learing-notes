在单位正方形 [0, 1] × [0, 1] 中放置 26 个圆。

约束：
- 圆的半径必须为正。
- 每个圆必须完整位于正方形内。
- 圆之间不能重叠，允许相切。

目标：
最大化 26 个圆的半径之和。

程序接口：
实现不带参数的 solve() 函数。
返回一个列表，每个元素是 [x, y, radius]。

进化范围：
- 仅允许修改 # EVOLVE-BLOCK-START 与 # EVOLVE-BLOCK-END 之间的代码。
- 第一块用于导入 Python 标准库，第二块用于初始化、优化及辅助函数。
- initialize() 生成布局；optimize(circles) 改进布局。可修改二者及增加辅助函数。
- 保留所有标记和块外的固定代码，尤其是 solve() 调用接口。
- 不允许修改评测器。

评测说明：
- 仍只有一个优化目标：sum_radii，即半径之和。
- 几何合法性容差为 1e-9。constraints 中 boundary/non_overlap 是扣除容差后的约束残差，必须 <= 0。
- 合法布局额外记录 radius_cv（半径总体标准差除以平均半径）与 boundary_fraction（至少接近一条边的圆所占比例）。
- 接近边界的阈值独立设为 1e-6。这两个布局特征不增加得分，不代表优化算法类别。
- 当前所有运行采用 standard 阶段的同一预算；重复复核每次均重新执行完整 solve()。
