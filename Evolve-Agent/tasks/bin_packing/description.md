在线一维装箱：箱容量100，每个物品大小是正整数。物品按给定顺序到达，不允许重排。

只进化 choose_bin(item, remaining)：item 为当前大小，remaining 为现有箱子的剩余容量元组。返回可放入的现有箱子编号，或 len(remaining) 表示新建一个箱子。固定 solve() 负责生成12个公开确定性实例、顺序调用启发式并返回分配，不能修改。

固定评测器独立重建实例，验证每个物品恰好分配一次、箱子按在线顺序创建、总容量不超限。

目标最大化12个实例上 ceil(总物品大小/100)/使用箱数 的平均值。这个容量下界只是比较基准，不保证每个实例可以达到；不得称其为已知最优解。

初始程序为 first fit。可实现 best fit 或更复杂的仅利用当前物品/已打开箱子状态的评分规则。实例生成种子公开，因此这只是框架可替换性/公开训练集实验，正式泛化研究必须另设隐藏实例与独立测试分布。

特征为平均箱子空闲比例 mean_waste，以及各箱空闲比例的变异系数 waste_cv，不增加质量分数。只使用Python标准库，不访问文件/网络/环境或创建子进程。
