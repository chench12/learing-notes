## 三种策略接在哪里

三种策略共用同一个岛屿特征档案，只替换“从当前岛屿的占用格中选择哪个父代”。它们不替换整个智能体，也不决定模型参数更新。

调用路径：`controller.run_search` → `generation.generate_once` → `session.select_parent` → `selection.sample_parent`。选择完成后，统一进行父代复测、上下文构造、模型生成、补丁校验、子代评测和档案更新。

| 配置 archive.parent_sampling | 本项目规则 | 探索与利用 |
|---|---|---|
| uniform_cell | 从占用格均匀抽样 | 对不同格等权；格内竞争保留高质量程序 |
| softmax_cell | 按质量与周期下降温度抽样 | 高温更分散，低温偏向高分；借鉴 FunSearch，并非完整 FunSearch |
| puct_cell | 直接子代最佳奖励加访问次数探索项，选择最大值 | 兼顾已证明有产出的父代与较少访问的分支；借鉴 TTT-Discover，并非完整复现 |

当前PUCT的先验、奖励缩放、同分处理、谱系访问计数都是明确记录的本项目规则。岛屿与格子本身提供额外多样性；不能把“均匀”解读为完全没有利用，也不能在无真实对照时判定PUCT最好。

## 这次新增的闭环

1. 固定任务、完整父代和输出协议；按字节预算加入完整历史参考程序、材料、实际日志和采样指令。保存取舍理由及来源ID。
2. 选模型、冻结生成计划、预留预算，再调用一次。程序请求与元指令请求共用 calls 账本，失败同样计入。
3. 保存响应，解析精确补丁，检查语法和固定骨架，再运行独立评测。保存响应后中断可以离线恢复，结果未知的调用不自动重发。
4. 更新档案；合法且超过调用前最佳的子代可触发独立同预算复核。复核结果不进入搜索奖励。
5. 可选地周期提出附加指令，保存独立谱系；以固定窗口的父子增量报告信用。这仍有混杂因素，不是因果贡献。
6. 达到预算、步数或STOP条件就保存控制状态。多个独立实验可有界批处理；同一实验内部仍串行。
