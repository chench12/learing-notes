# 100步串行模型搜索

配置：configs/circle_packing.docker.100.json，基于已验收的Docker配置创建，模型、任务、固定镜像、单次3秒求解预算、4岛、均匀抽格、历史参考及模板权重均沿用原配置。

这是一场从原始网格种子开始的新100步实验，不继承三步预实验的候选或2.616725867642344成绩。原实验冻结的总上限是10步，不能通过--steps 100扩充，也不要修改旧manifest。旧实验完整保留，可另作预实验记录。

| 预算项 | 上限 |
|---|---:|
| 生成尝试 | 100 |
| 模型调用 | 100 |
| Token预算（未知用量保留估计额度） | 2,000,000 |
| 累计评测预算 | 7,200秒 |
| 累计墙钟预算 | 14,400秒 |
| 单次模型输出上限 | 4,096 Token |

时间为预算上限，不是预计耗时；墙钟沿用框架的保守累计规则，并非操作系统硬截止。任何预算耗尽都可能早于100步停止。未配置服务平台单价，不能提供金额估算或金额上限；Token上限不是人民币或美元费用上限。

元指令进化、自动重复复核仍关闭，因此主循环最多请求100次程序生成。补丁、语法和几何失败仍作为实验结果记录，100步不等于100个合法新程序。模型连接结果未知或执行基础设施错误会停止循环，不自动重发。

使用创建实验时准备采用的pytorch环境，启动桌面Docker Desktop - D Drive入口，在已设置RELAY_API_KEY的同一终端执行：

```powershell
cd D:\Evolve-Agent
python -X utf8 -m Examples.run_search --config configs/circle_packing.docker.100.json --steps 100
```

命令会创建真实实验并产生模型费用，本次配置准备没有创建实验、运行候选或调用模型。记下输出的实验目录；运行中不要修改配置、任务或框架，不同时打开其它搜索/评测进程争用CPU。

正常停止后，打开该实验的README.md、summary.json、best.py和best_solution.json。根目录摘要在本次控制器退出时更新，长循环中不会每一代刷新。逐代结果仍持续保存在generations、evaluations与calls中。

如正常中断后要继续同一场实验，在原环境使用真实目录：

```powershell
python -X utf8 -m Examples.run_search --experiment experiments/exp_本次实际编号 --steps 100
```

这个恢复命令仍受原实验累计100步/100调用预算约束，不会再额外扩充100步。结果未知的请求需先检查平台记录和本地恢复报告，不能靠重启命令绕过。

这是均匀抽格策略的一次运行，可用于观察得分曲线、合法率、候选多样性和Token消耗；策略比较还需匹配其它选择器、相同预算和多个独立搜索种子。最终最佳程序仍应单独重复复核。
